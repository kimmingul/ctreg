# 축별 현황·분포·추이

순위(누가 1등)가 아니라 **분포**(어떻게 나뉘나)·**추이**(해마다 어떻게)를 물은 것이다. 절차는 순위와 같고
답의 모양이 다르다.

## 절차

1. 주제(검색어)를 정하라 — 국문·영문 같이. 주제가 없으면(예: "국내 임상시험 의뢰사 분포") term 을 넓게
   잡되(예: "임상,clinical") 그것이 모수를 정한다는 것을 밝혀라 — 전체 12,000여 건을 다 묶는 축은 없다.
2. **`aggregate_trials` — 축마다 한 번, 여러 축이면 한 턴에 동시에.** by: year(추이) · sponsor(의뢰사) ·
   site(실시기관) · investigator(연구자) · intervention_type(중재 종류) · drug(의약품) · condition(질환).
   page-size 는 분포면 20~50, 추이면 50(연도 전부).
3. **국내가 아니면 registry `["ctgov"]`.** ctgov 는 집계 API 가 없어 검색을 1,000건까지 받아 센다 — 결과에
   `aggregate_truncated` 가 있으면 모수 중 1,000건 안의 분포라고 말하고, 검색어·status 로 좁혀 다시 물어라.
   ctgov 의 이름은 원문이라 "Type 2 Diabetes" 와 "Diabetes Mellitus, Type 2" 가 갈린다 — 합쳐서 말하되 그렇다고 밝혀라.
4. 추이는 연도순으로 다시 배열해 말하라(도구는 건수순으로 낸다). 분포는 상위 몇 개와 "그 밖" 의 합.
5. 한 시험이 여러 의뢰사·기관·약물에 속할 수 있다 — **축 안의 합은 모수보다 클 수 있다**, 비율로 말할 때
   분모를 모수(matched)로 할지 항목 합으로 할지 밝혀라.

## 답의 모양

- 첫 줄: 모수 — "검색어 ○○에 걸린 CRIS 시험 N 건(사본, 수집 ○○)".
- 축마다 문단 하나: 상위 항목과 수, 눈에 띄는 것 하나.
- 마지막: 근거와 한계 — `provenance` 그대로(의뢰사·기관은 표준명 매핑 비율, 의약품·질환은 사전 매칭이라
  사전에 없는 것은 빠짐), CRIS 만임, 다른 레지스트리는 안 봤음.
- 표를 길게 나열하지 마라 — 페이지가 표를 보여준다.
