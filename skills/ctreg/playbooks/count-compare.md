# 건수 비교

## 절차
1. 비교 축마다 하나씩, **한 턴에 동시에**. kctis 가 있으면 SQL(국내 `v_cris_unified`/`v_mfds_trials`, 세계 aact
   `studies`), 없으면 ctreg `count_trials`(registry 하나씩).
2. 같은 레지스트리 안의 범주(상·상태)별 건수는 한 시험이 여러 범주에 들 수 있다.

## 답에 반드시 밝힐 것
- **범주별 건수를 더해 전체로 말하지 마라.** 레지스트리 간 건수도 더하지 마라 — 같은 시험이 여러 곳에 등록된다.
- 못 물은 레지스트리는 0 이 아니다. 출처와 시각.
