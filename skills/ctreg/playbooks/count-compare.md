# 건수 비교

## 절차

1. 비교 축마다 `count_trials` 를 따로 — **한 턴에 동시에**. 레지스트리를 비교하면 registry 를 하나씩.
2. 같은 레지스트리 안에서 범주(상·상태)별로 세면 한 시험이 여러 범주에 들 수 있다.

## 답에 반드시 밝힐 것

- **범주별 건수를 더해 전체로 말하지 마라.** 합이 전체와 다르면 그 사실을.
- 레지스트리 간 건수도 더하지 마라 — 같은 시험이 여러 곳에 등록된다.
- 못 물은 레지스트리는 0 이 아니다.
