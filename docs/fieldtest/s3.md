## 2. 사용자 질문에 대한 최종 답

네, NCT04280705 (ACTT — Adaptive COVID-19 Treatment Trial, NIAID 주관, Remdesivir 대 위약 비교, 3상, 2020년
완료, 등록 1,062명) 시험에는 유해사례 결과가 보고돼 있습니다. 전체 110개 유해사례 항목이 18개 장기계통(organ
class)에 걸쳐 등록돼 있고, 이 중 **심장 계통(Cardiac disorders) 관련 유해사례가 15개 항목** 보고돼 있습니다.
전부 "serious"(중대 이상반응)로 표시돼 있고, 분모(atRisk)는 1,048명입니다.

주요 심장 관련 유해사례 (건수 순):

- 심방세동(Atrial fibrillation) — 6건

- 심근경색(Myocardial infarction) — 4건
- 상심실성 빈맥(Supraventricular tachycardia) — 3건
- 심실빈맥(Ventricular tachycardia) — 2건
- 급성 심근경색(Acute myocardial infarction) — 2건
- 심부전(Cardiac failure) — 2건
- 심인성 쇼크(Cardiogenic shock) — 2건
- 급성 관상동맥 증후군(Acute coronary syndrome) — 1건

1. 이 수치는 레지스트리 등록 정보이며, **투약군(Remdesivir)과 위약군을 나눈 수치가 아니라 두 군을 합친 것으로
   보입니다** (분모 1,048명이 시험 전체 안전성 분석 대상자 수에 해당). 어느 약이 어떤 유해사례를 더 많이
   유발했는지는 이 도구의 출력만으로는 구분할 수 없습니다 — 이 부분은 확실하지 않으니 필요하면 원문
   (clinicaltrials.gov/study/NCT04280705) 결과 섹션의 arm별 표를 직접 확인하시길 권합니다.
2. 이 레지스트리 기재사항은 임상시험 적격 판정이나 인과관계 평가가 아닙니다 — 유해사례가 시험약 때문에
   발생했다는 뜻이 아니라, 시험 중 관찰·보고된 사건이라는 뜻입니다.

## 3. 헤맨 지점

- `--ae-organ` 을 처음 실행했을 때, 응답에 `results_summarized` 경고가 여전히 남아 있어서 순간
  "필터가 안 먹혔나?" 하고 재확인했음. 실제로는 `adverse.expanded: 15` 로 바뀌어 있고 `items` 에
  심장 계통 15건이 정확히 채워져 있어서, 경고는 "다른(전개 안 된) organ 들이 아직 남아 있다"는
  뜻이지 "요청한 organ이 전개 안 됐다"는 뜻이 아니라고 판단하고 넘어감. 처음엔 이 구분이 명확하지
  않아서 한 번 더 출력을 꼼꼼히 대조했음.
- arm(Remdesivir vs Placebo)별로 유해사례를 나눠서 볼 수 있는지 확인하려고 `--full` 옵션을 시도해봤는데,
  `--full` 은 organ 필터를 무시하고 outcomes + adverse 전체를 전부 펼치기만 할 뿐, adverse 항목 구조
  자체는 `{organ, term, serious, affected, atRisk}` 로 동일했음 (arm 필드 없음). `--help` 에도
  arm 관련 옵션이 없어서, 이 도구는 애초에 arm별 분리를 지원하지 않는다고 결론 내림. 혹시 `--raw`
  옵션을 쓰면 원본 ctgov 페이로드에 arm 분리 데이터가 있을 수도 있겠다 싶었지만, 이건 사용자 질문
  범위를 넘어서는 탐색이라 판단해 더 파고들지 않고 멈췄음.
- `--section` 옵션이 `--help` 에 나와 있는데 실제로 써보지는 않음 (`results` 명령이 기본으로
  outcomes/adverse/flow/baseline 4개 섹션을 다 주길래 굳이 `--section adverse` 로 좁힐 필요를
  못 느낌). 이게 다른 동작을 하는지는 확인 안 해봄.

## 4. 확신이 없는 지점

- **가장 큰 불확실성**: `affected`/`atRisk` 수치가 Remdesivir군과 위약군을 합친 값인지, 아니면
  둘 중 한 군(예: 전체 안전성 모집단)만의 값인지 도구 출력만으로는 100% 확신할 수 없음. `atRisk: 1048`
  이 `ctreg get` 의 `enrollment.count: 1062` 와 약간 다른데(14명 차이), 이게 "안전성 분석 대상자만
  집계했다"는 뜻인지 "특정 군만의 수치"인지 구분이 안 됨. 실제 ACTT-1 논문(NEJM, Beigel et al. 2020)
  기억으로는 안전성 분석 대상이 1048명 정도였던 것 같은데, 이건 도구가 알려준 게 아니라 내 배경지식이라
  답변에 확신을 갖고 넣기엔 애매해서 답변에서는 "확실하지 않다"고만 명시함.
- `serious: true` 가 15건 전부에 붙어 있는데, 이게 "이 organ의 모든 사건이 실제로 SAE(중대 이상반응)로
  보고됐다"는 뜻인지, 아니면 이 도구가 애초에 SAE만 추출해서 보여주는 것인지 (즉 non-serious 심장
  이벤트는 애초에 집계 대상이 아닌지) `--help` 나 경고 메시지만으로는 구분이 안 됨. `--ae-term` 옵션도
  있어서 특정 term만 더 좁혀볼 수 있었지만, "serious 여부와 무관하게 전체를 보여주는 게 맞는지"는
  검증 못 했음.
- `results_summarized` 경고가 다른 organ(예: Respiratory 13건, Infections 13건)에 대해서는 여전히
  안 펼쳐진 상태로 남아있는데, 사용자가 "심장 관련"만 물었으므로 답변에는 심장 계통만 넣었음. 만약
  사용자가 "다른 장기 계통도 궁금하다"고 하면 organ별로 하나씩 다시 펼쳐야 하는데, 한 번에 여러
  organ을 펼치는 문법(`--ae-organ` 반복 가능 여부)은 시도해보지 않아서 모름.
