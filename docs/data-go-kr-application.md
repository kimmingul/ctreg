# 공공데이터포털 활용사례 등록 · 운영계정 신청 문안

- **대상 데이터:** 질병관리청_임상연구 DB (data.go.kr 3033869)
- **언제 쓰나:** 공개 MCP 서버를 **띄운 뒤**. 활용사례 등록 → 운영계정 전환 → 트래픽 증량 신청 순이다.
- **성격:** 신청 화면에 붙여 넣을 문안. 서버 URL 과 날짜는 그때 채운다.

> 이 문서는 사실을 소유하지 않는다. 라이선스 검토와 조건은 `slice-2-prerequisites.md` 의
> 「CRIS 라이선스 검토」 절이 정본이다.

## 활용사례

**서비스명**
ctreg — 임상시험 레지스트리 통합 조회 MCP 서버

**활용 분야**
연구 · 보건의료

**서비스 URL**
`https://<서버>/mcp` ← 띄운 뒤 채운다

**소스 코드**
https://github.com/kimmingul/ctreg (Apache-2.0)

**활용 내용**

임상시험 레지스트리 다섯 곳(ClinicalTrials.gov, ISRCTN, WHO ICTRP, EU CTIS, 그리고
질병관리청 CRIS)을 하나의 정규화된 스키마로 조회하는 도구입니다. 명령줄 도구(npm
`@kimmingul/ctreg`), Claude Code 플러그인, 그리고 MCP(Model Context Protocol) 서버 세
가지 형태로 제공되며, 이 활용사례는 그중 MCP 서버입니다.

질병관리청_임상연구 DB 오픈API 는 이 도구의 국내 레지스트리 어댑터가 사용합니다. 목록조회와
상세조회 두 오퍼레이션을 그대로 쓰며, 응답을 다른 레지스트리와 같은 스키마로 정규화해
연구자가 국내외 임상시험을 한 번에 검색할 수 있게 합니다.

특히 CRIS 가 국문·영문을 나란히 싣는 점을 활용해, 한국어 연구자·기관·약품명을 **실제 등록된
영문 표기**로 변환한 뒤 해외 레지스트리를 검색하는 경로를 제공합니다. 로마자 표기가 사람마다
달라 해외 레지스트리 검색이 누락되는 문제를 CRIS 데이터로 해결합니다.

**이용 조건 준수**

- **비영리:** 개인이 개발·운영하는 무료 서비스이며, 서버 인프라 비용은 나눔스페이스
  주식회사(Nanum Space Co., Ltd.)가 부담합니다. 회사는 비용을 부담할 뿐 이 서비스로 수익을
  얻지 않으며, 광고·유료화·상용 제품 번들이 없습니다. 공공누리의 "상업적 이용" 은 영리행위와
  직·간접으로 관련된 이용을 뜻하고, 이 서비스는 그에 해당하지 않습니다.
- **출처표시:** 모든 응답 레코드에 "출처: 질병관리청 임상연구정보서비스(CRIS)
  https://cris.nih.go.kr — 공공누리 제2유형" 이 필드로 실려 나갑니다. 공공누리가 요구하는
  출처 웹사이트 하이퍼링크를 포함합니다.
- **변경 없음:** 데이터를 가공하되 내용을 바꾸지 않습니다. 정규화 과정에서 손실이 있는 필드는
  원문을 함께 싣습니다(`--raw`).

**예상 트래픽**
일 ______ 회 ← 실측 후 채운다. 서버를 띄우고 첫 2주간 `GET /stats` 의 `byDay` 를 근거로 적는다.
`byRegistry.cris` 가 이 API 를 실제로 부른 횟수다 — 총계가 아니라 이 수를 적는다.
(`/stats` 는 호출 수만 세고 사용자 수는 모른다 — 신청서에 "이용자 N명" 을 적을 근거가 없으니 적지 않는다.)

## 운영계정 신청 사유

개발계정의 일 10,000회 한도로 개발과 검증을 마쳤습니다. 공개 MCP 서버로 전환하면서 불특정
다수의 연구자가 사용하게 되어 트래픽 증량이 필요합니다. 위 활용사례에 등록한 서비스이며,
공공누리 제2유형 조건(출처표시·비영리)을 코드 수준에서 지키고 있습니다.

서비스 URL 이 법인 명의의 클라우드 인프라(Fly.io, Nanum Space Co., Ltd. 조직)에 있는 것은
인프라 비용 부담 주체가 그쪽이기 때문이며, 서비스의 운영 주체와 비영리 성격은 위 활용사례에
적은 대로입니다.
